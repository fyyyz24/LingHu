# 技术说明与交付边界

## 已实现

前端为原生 HTML/CSS/JavaScript。`dist/index.html` 组织页面，`app.js` 管理会话，`engine.js` 执行要点及显式危险表达规则，`case-import.js` 校验并持久化病例，`evidence-library.js` 提供来源检索与引用，`processing.js` 提供可取消的处理动画，`clinical-experience.js` 组织影像与事件回放。

病例以 5 阶段、3 层级组织。规则判定依赖关键词/别名，见习与实习默认每阶段 2 个要点、住培 3 个；最后阶段附安全优先要点检查。该方法不具备完整语义理解，不代表模型医学准确率。

报告统计实际事件；覆盖率按已提及唯一要点计算。没有后台 API，未调用 Hulu-Med。状态动画和公开教学依据摘要不等于模型内部推理，也不应被命名为已执行推理的 token 流。

## 数据流与隐私

用户 JSON → 本地结构/来源声明校验 → localStorage 写入成功 → 注册病例/规则/证据 → 病例库和训练选择器。写入失败不部分入库；损坏存档不自动覆盖。图片为内嵌数据或本地资源，不自动联网请求。文献仅在用户点击时打开外部网页。

禁止若干身份键不能识别自由文本中的全部敏感信息。真实病例须事先完成人工脱敏和合法授权。公开图像的许可不自动证明临床研究、隐私或二次训练合规。

## 可复现材料

`scripts/build-materials.cjs` 生成种子数据、图片授权清单、带图导入包；`scripts/validate-materials.cjs` 实际运行测试并保存结果；`scripts/package-submission.py` 使用白名单打包并逐文件生成 SHA-256 清单。

应用无需编译，`dist` 即运行产物。工具仅依赖 Node 内置模块、Python 标准库；不伪造训练依赖或复制不需要的第三方库。训练环境需另行锁定真实安装版本。
