# 程序运行指引

## 环境与启动

应用为原生 HTML/CSS/JavaScript，无 npm 运行依赖、无编译步骤，无需 GPU。`dist/` 同时是前端源代码和可运行发布目录。推荐现代 Chrome / Edge。

在仓库根目录运行 `python -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173/。无 Python 时双击 `dist/index.html`；访问指南原文仍需联网。

开发验证需要 Node.js 18+；材料 ZIP 打包需要 Python 3.10+ 标准库。不需要 `pip install` 或 `npm install`。

## 直接上传电脑里的图片

1. 数据工坊 → 选择病例 JSON，或点击“填入纯文字示例”（自动分配新 id，避免与之前导入重复）。
2. “上传本地病例图片” → **选择本地图片**。支持 PNG / JPEG / WebP，每张原文件 ≤ 1.1 MB；显示预览、尺寸、大小。可替换或移除，不压缩、不修改原图。
3. 填写图片类型、说明、作者/提供者、授权范围和来源说明。本地图片**不要求有公开网址**。不要在说明中填写患者身份信息。
4. 勾选病例及图片权限确认 → 校验并预览 → 确认导入。病例与图片一起保存在本机，病例库详情和证据面板都可查看，刷新后仍保留。
5. 校验后可先点“下载含图片的病例包”备份。图片自动内嵌，不用手动编写 base64。

本次上传一张图片，附加到 JSON 原有 assets；不会替换旧图。重新选择病例 JSON / 填入示例会清除待附加图片，以免串到另一个病例。总量仍受 2.5 MB 存档限制；过大文件给出错误，不偷偷压缩医学影像。仅有一张图片不能自动生成完整病例，需先有病例文本。

## 预置带图片示例（可选）

1. 在数据工坊点击“下载带胸片示例”；也可直接取仓库 `dist/examples/TEACHING-IMPORT-01-IMAGE.json`。
2. 退出录屏模式，选择该 JSON。无需另选图片：胸片原始 PNG 已内嵌，断网也可显示。
3. 阅读来源与权限说明，确认已检查资料，点击“校验并预览”。应显示 **5 阶段、1 条来源、1 张图**。
4. 确认导入后，病例库显示 **呼吸困难教学练习 · 含胸片参考**。展开病例可看左侧信息与右侧胸片，点击图片放大、查看作者和许可。
5. 开始训练，检查五阶段及证据面板，再刷新当前网址，验证病例保留。

图片由 James Heilman, MD 发布，CC BY-SA 3.0，原样复制，无裁切、无新增病灶。它是另一公开病例的**右侧胸腔积液参考图**，并不是虚拟教学患者的原片，也不确认本例积液量或病因。原图在 `dist/assets/references/pleural-effusion.png`，许可见 `submission/THIRD_PARTY_NOTICES.md`。

新示例 id 为 `TEACHING-IMPORT-01-IMAGE`，与旧纯文字 `TEACHING-IMPORT-01` 可并存；重复导入同一 id 会拒绝，不覆盖已有记录。文件约 1.2 MB；准确字节数见材料清单。

## 自定义病例

JSON 字段以示例为准，schemaVersion 为 1。必须有来源/授权声明、人工脱敏确认、五阶段、每阶段三个要点、分层提示及有效证据 id。第五阶段第一个要点为安全优先核对项。

图片支持 PNG/JPEG/WebP base64，**每张编码文本不超过 1,500,000 字符**，最多六张；全部导入存档不超过 **2,500,000 字节、20 个病例**。包含图片的两个大病例可能超限，请勿把它当作大规模病历管理系统。禁止 SVG 与远程自动取图。未知检验填写“尚未获得”，不能补造结果。

导入审核状态属于导入者声明，结构校验不是医学审查，也不是自动脱敏。不要输入身份信息；浏览器清理站点数据会丢失病例和训练记录，请另存原始 JSON。

## 使用与录屏

- 固定同一浏览器、网址和端口。本地存储在不同入口间不共享。
- F8 / 录屏模式使用临时会话，不覆盖原有训练记录；刷新结束临时录屏。先正常导入，再进入录屏。
- 对话动画是输入整理、文献关联、规则核对、反馈组织的处理状态，不是 Hulu-Med 模型内部思维。
- 教师报告根据实际作答、提示与查阅事件生成；覆盖率不等于医学正确率。
- 证据面板可筛选、看定位、打开原文、导出引用；本地目录不是联网 RAG。
- 录制顺序：病例导入 → 图文病例 → 分层训练 → 证据 → 报告回放。MP4 及 200 MB 限制请在录制工具中设置，本仓库不自动录屏。

## 验证与故障排除

运行 `npm test`；随后 `node scripts/validate-materials.cjs`。无 npm 时分别用 Node 运行 `tests/` 下五个测试文件（材料测试依赖先生成数据）。

导入失败先看错误信息：同 id 使用新 id；配额不足不要覆盖现有存档，先保留 JSON；结构错误按提示修正。损坏存档会停止写入以保护原资料。图片不会通过远端补齐；带图 JSON 应有 `assets[0].dataUrl`。
