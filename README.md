# 灵葫——基于Hulu-Med的临床思维训练教学模型

## 打开与验证

双击 `dist/index.html` 可离线使用。推荐固定使用同一浏览器和同一入口，避免本机记录分散在不同站点存储中。

```powershell
python -m http.server 4173 --directory dist
node tests/engine.test.cjs
node tests/clinical-experience.test.cjs
node tests/functional.test.cjs
```

浏览器打开 http://127.0.0.1:4173/ 。

## 已实现交互

- 6 个病例、每例 5 阶段，逐阶段解锁；切换病例恢复各自进度。
- 回答分为方向待校准、证据不足、安全待复核与允许推进，非空文本不再一律通过。
- 教学依据抽屉：展示原回答、识别要点、遗漏项、推进规则、追问方向和资料入口。
- 见习／实习／住培提示，以及轻／中／强提示；支持同题三层级对比。
- 教学报告按实际事件生成：覆盖率、回答／提示／资料查阅次数、时间线、复盘建议。
- 六个病例均可展开“左文字、右影像”详情卡，同时呈现主诉、现病史、查体、检验、适用于该病例的公开影像／体征照片及当前阶段。
- 教师报告新增五阶段能力雷达、逻辑性／安全性／证据使用／层级匹配四维看板，以及可播放、可点选的思维递进轨迹。
- 每次回答生成独立证据链编号，串联“学生判断 → 教学反馈 → 教材／指南证据”；具体章次、版本与条目号在医生审核前保持待核验状态。
- 回答草稿、学习层级、各病例进度保存到本机；可导出 JSON 学习记录或打印为 PDF。
- 独立录屏模式（按钮或 F8）：新开临时会话，不覆盖原有训练记录；退出恢复原状态。刷新会结束临时录屏会话。
- 非阻塞录屏导览：8 镜头、总计 6 分 30 秒，支持收起、跳转与退出。
- 病例搜索无结果提示、键盘焦点、弹窗关闭、响应式布局与打印样式。
- 数据工坊可下载医生病例编排 JSON 模板。

## 实现边界

本版本是本地展示交互代码，未接入 Hulu-Med 权重、推理服务或真实微调任务。回答核对使用可替换的文本要点规则，不具备完整语义理解；否定表达与危险方向检查仅覆盖显式模式，不能用于临床安全认证。依据面板是教学反馈摘要，不是模型内部思维或真实推理日志。

覆盖率为同一会话已提及的唯一要点数 / 15；重复提交不会重复加分，不衡量答案医学正确性。见习和实习为每阶段至少 2 项，住培为 3 项，均为当前交互阈值，待医生审核。第五阶段另有优先要点检查。

基础模型论文数据与本项目数据分开，不把 16.7M、30 项基准当作本项目新增训练或实测成果。模型适配页为技术路线；没有执行训练。教材指南的具体条目尚未经过临床教师绑定审核。

## 医生接入前的素材状态

6 个病例保留现有教学扩写，并不等于 6 份真实病历。年龄、体征、参考答案、反馈规则等均需医生审阅。CASE 03 的“钙化阳性”设定不应归属于论文第 51 页的原始结论，来源已更正为任务形式参考。

2026-09-27 更新：6 例均已加入真实公开影像或体征照片作为同病种 / 鉴别学习参考，并非当前教学人物的原始病历。每图展示作者、原页、许可、图注与适用边界；本地保存，不依赖外链加载。原始临床事实、检验值和医生审核状态没有用网络资料伪造补齐。

新增本轮思维路径与报告回放：证据 → 学生原始判断 → 要点核对 → 教学反馈与修正。支持节点点击、播放/暂停、0.5×/1×/2×、进度拖动、五阶段切换和历史轮次对照；无回答不生成轨迹。切换页面/病例或隐藏窗口会暂停，尊重减少动画设置。它是教学过程摘要，不是模型内部思维链。

图像及学习资料来源见 `dist/medical-resources.js`；许可与适用边界在病例详情中可直接查看。放大器不会重建或修改医学图像。具体条目与当前病例的临床适用性仍由医生审核。

详见《医生交接与录屏检查.md》。现支持结构化病例 JSON 导入，但没有自动医学审核或自动脱敏，也不会替医生签署审核状态。

## 2026-09-27 功能修复

- 移除只有静态说明的独立评测中心，实际事件统计、雷达与训练回放保留在教师报告。
- 对话提交后展示输入整理、文献关联、要点核对、反馈组织四阶段加载动画，支持取消，锁定重复提交；换页、换病例、重置和录屏模式切换会取消未完成请求。动画有短暂呈现间隔，不是模型计算耗时或 token 流。
- 当前仍是本地教学引擎，未配置 Hulu-Med 推理服务；没有模型内部思维日志。若需真实服务摘要，应由后端提供可公开的处理状态和带引用的结论摘要，不能将动画冒充后台调用。
- 证据面板可按病例、标题/章节/DOI、来源类型筛选，打开原文、查看定位和导出引用。每次作答保存当时的关联文献快照；未核验的教材章节占位不再作为证据展示。检索为本地登记目录，不是联网 RAG。

### 如何导入病例

1. 数据工坊 → 下载可导入模板，或点击“填入可导入示例”。示例来自内置教学编排，不是真实患者。
2. 按 JSON 修改 `id`、病例信息、五阶段事实/问题/参考答案/提示，登记 `references`，每阶段用 `evidenceIds` 指向来源 id。每阶段恰好三个要点；第五阶段第一个要点用于安全优先检查。
3. 图片可留空；可用 `assets[].dataUrl` 嵌入 PNG/JPEG/WebP base64，每图编码文本不超过 1 MB；填写图注、作者、许可和原始链接。禁止 SVG 与远程自动加载，避免隐藏网络请求。
4. 人工脱敏并勾选权限确认，点击“校验并预览”，通过后“确认导入病例库”。结构校验不等于医学审核；审核状态只是导入者声明。
5. 成功后病例库与训练下拉菜单立即可见，可展开详情、五阶段训练和教师报告。刷新同一浏览器同一网址可恢复。不同域名/端口/浏览器不共享记录。

最多导入 20 例，导入存档总计不超过 2.5 MB。重复 id 不覆盖现有病例，存储失败不部分入库。清理站点数据会删除导入病例，务必保留原始 JSON。导入病例与训练记录不进入 Git 仓库，也不上传服务器。

## 文件结构

- `dist/index.html`：页面结构、抽屉、报告与导览。
- `dist/cases.js`：教学病例、任务来源、审核元数据与路线说明。
- `dist/engine.js`：纯函数核对规则、状态结构、报告统计。
- `dist/app.js`：页面状态、对话、持久化、导出与录屏会话。
- `dist/workflow.css`：可读性、响应式、依据面板、报告打印。
- `dist/medical-resources.js`、`dist/assets/references/`：6 例公开参考素材及来源登记。
- `dist/clinical-experience.js`、`dist/clinical-experience.css`：影像查看、学习资料和事件驱动回放。
- `tests/clinical-experience.test.cjs`：素材、来源和轨迹事件隔离校验。
- `dist/styles.css`、`dist/enhancements.css`：保留的基础风格与品牌动效。
- `tests/engine.test.cjs`：病例参考回答、分支、统计、状态与页面绑定检查。

## 记录与隐私

当前无后台上传接口。训练文字保存在当前浏览器本地，导出的 JSON 含完整回答。不要填写患者姓名、证件号、联系方式等敏感信息；录屏前关闭系统通知，检查浏览器和导出文件没有患者身份信息。“重置训练”只针对当前病例，应先导出需要保留的记录。
